# C1 task-only 条件准备

C1 复用当前冻结 CLM harness、Qwen3.5-9B、原训练与验证题单、8×32 逻辑批以及 70 更新设置。训练优势中的效率系数设置为 0。CLM 的任务失败与格式惩罚沿用 C2，任务优势的组级标准化保持相同。

原生参数解析与 C2 比较只有九项预期差异，涉及独立实验身份、输出/检查点/审计/入站门路径和训练环境变量。具体值见 `EFFECTIVE_DIFF.json`。

通过原生 `--train-env-vars` 将 `POLAR_DUAL_CHANNEL_W_EFF=0` 显式传给 GPU 训练角色。Ray head 已有的 0.25 环境需要覆盖，单独修改启动 shell 的环境不足以验证该行为。CPU 检查已经在父环境 0.25 下取得实际 0，并用原生优势函数得到 task-only 结果。

首次 CPU 检查假定无 GPU 的 Ray actor 自动具有空设备可见性，实际继承了 head 可见设备。该假设失败已保留日志和退出记录。修正对 CPU 检查角色显式设置空设备可见性，原 C1 GPU 配置保持。CPU worker 退出已实核。

本目录尚未派发训练。未来启动需要独立 owner/意图记录、空闲的已授权 GPU4/5、初始权重与题单核对，并在真实 GPU 训练角色中再次核对效率系数。
